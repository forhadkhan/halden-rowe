# Hero tower: ChatGPT image prompt

Drop the result at `src/assets/hero/tower.png` (any size; the hero is height-driven). Ask for a **transparent background**
(ChatGPT image generation: "transparent background, PNG"). If it returns a flat background, run it through
remove.bg or any background remover, then save as PNG.

## Prompt

> A single tall, slender modern residential skyscraper, photographed straight-on from street level looking up slightly,
> centred, full building visible from base to crown. Pale warm-white stone and glass facade with elegant vertical
> fins, curved rounded balconies on every floor, a subtle stepped crown, soft daylight, gentle realistic reflections,
> crisp architectural-photography detail, photoreal, premium real-estate marketing quality.
> Isolated cut-out on a fully transparent background (PNG with alpha), no sky, no ground, no other buildings, no trees,
> no people, no text, no watermark, no shadow on the ground. Portrait orientation, about 1:3 aspect ratio (for example
> 1024 x 3072 or the tallest size available), clean sharp edges.

## Notes

- Warm white / stone tones match the site palette (ivory, ink, brass); avoid blue-tinted glass.
- The base of the tower sits behind the search pill, so a flat or faded bottom edge is fine.
- Current file is a placeholder crop from the NYC listing photo.
